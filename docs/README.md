# Visual X# documentation

This directory documents the repository as it exists today and separates intended architecture from current implementation.

- [Architecture](ARCHITECTURE.md) — stage ownership and data flow.
- [Implementation status](IMPLEMENTATION.md) — what is implemented, transitional, or not connected.
- [Building and testing](BUILDING.md) — supported Windows toolchain and verification commands.
- [CLI](CLI.md) — accepted command surface and current limitations.
- [Project files](PROJECT_FILES.md) — the `Visual.XSharp.kts` model.
- [Specification guide](SPECIFICATION.md) — how to read and maintain `Spec/`.
- [Repository layout](MONOREPO.md) — component ownership.
- [Contributing](CONTRIBUTING.md) — change and verification rules.

The language is experimental. Documentation must describe unsupported or transitional behavior explicitly rather than present
the intended pipeline as fully connected.
